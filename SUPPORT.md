# Support

## Usage questions

Open a Question issue and include:

- the skill name
- the agent runtime and operating system
- Python and Tea versions
- the command or user request that triggered the skill
- sanitized output and the expected behavior

Remove tokens, passwords, cookies, private repository content, internal domains,
and personal information before posting.

## Bugs and feature requests

Use the Bug Report or Feature Request form. Reproducible examples should use a
temporary Gitea instance rather than a production repository.

## Security issues

Do not request security help through a public issue. Follow `SECURITY.md` and use
GitHub's private vulnerability reporting instead.

This project provides community support on a best-effort basis. Questions about
Gitea or Tea themselves should be reported to their respective upstream projects.
